# healthcare-performance-analysis
Interactive Tableau dashboard analyzing healthcare performance, patient visits, satisfaction ratings, waiting time, consultation time, departments, insurance types, age groups, and peak appointment periods.
Healthcare Performance Dashboard

📊 Project Overview

This Tableau project analyzes healthcare performance and patient visit data to understand patient satisfaction, waiting time, consultation time, department performance, insurance types, patient age groups, and peak appointment periods.

🛠️ Tools Used

* Tableau
* Data Cleaning
* Data Visualization
* Dashboard Development

📈 Key KPIs

* Total Visits: 2,200
* Average Satisfaction Rating: 2.723
* Average Wait Time: 62.35
* Average Consultation Time: 27.48

🔍 Dashboard Analysis

The dashboard includes:

* Visit by Department
* Cleaning Analysis by Hospital
* Satisfaction by Department
* Visits by Patient Age Group
* Visits by Insurance Type
* Peak Time Analysis

💡 Key Insights

* Orthopedics recorded the highest number of visits among the departments shown.
* Private insurance accounted for the highest number of visits among the insurance categories.
* Senior, adult, and child patients represented the major age groups in the dataset.
* Evening appointments had the highest number of visits among the time slots.
* Facility cleanliness and departmental satisfaction vary across hospitals and departments.

🎯 Business Objective

The objective of this dashboard is to provide healthcare organizations with a clear view of patient activity and service performance, helping identify areas for improving patient satisfaction, reducing waiting times, and optimizing healthcare operations.
